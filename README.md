# 断舍离整理教练

一个手机端优先、可安装、可离线使用的私人整理教练 PWA。

它不会把断舍离理论变成一套生硬测试题。用户只需要：

1. 选择一个小范围（如一层衣柜、一个抽屉或一个收纳箱）
2. 拿起当前这一件物品
3. 回答 2–4 个自然问题
4. 获得“留下 / 转卖 / 捐赠 / 舍弃 / 观察3个月”的明确决定
5. 在本次结算中查看数量与已减少重量

## 在线使用

https://danshari-organizer.cgkqpc2d8s.chatgpt.site

首次联网打开后，可通过手机浏览器“添加到主屏幕”。整理数据只保存在当前设备的浏览器中，不上传到服务器。

## 本地运行

```bash
npm ci
npm run dev
```

## 设计原则

- 方法论藏在判断里，不要求用户学习术语
- 每次只问一个问题，已知信息不重复询问
- 用户提供真实感受，教练负责给出明确决定
- 观察区严格受控，不把“舍不得”当成留下理由
- 只关注当前区域与当前物品，不制造数量焦虑
